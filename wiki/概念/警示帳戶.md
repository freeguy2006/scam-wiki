# 警示帳戶

## 定義
因為涉及詐騙金流，被銀行依警方通報列為警示、限制使用的帳戶。

## 運作方式
- 民眾被騙匯款後報案，警方透過「警示帳戶聯防通報子系統」通報銀行，把收款帳號列為警示；綁定虛幣交易所的虛擬帳號也會列警示，並以 API 通報交易所（src-07）。
- 出借或寄出帳戶的人，自己的帳戶也可能被列為警示帳戶，衍生信用與法律責任風險（src-11）。中部女大學生寄出提款卡後，發現無法轉帳，才知道帳戶已被列警示（src-12）。

- [[假愛情交友]]：被要求代收款項後轉購比特幣，帳戶被列警示（src-13）。
- 帳戶被列警示時：保存對話紀錄、匯款明細與截圖，通知銀行與警方；可以下載解除警示申請書，親自到警察機關辦理（src-15）。
