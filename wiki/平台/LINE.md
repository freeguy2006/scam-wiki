# LINE

## 平台簡介
通訊軟體。幾乎每種手法都會出現：詐團把被害人從[[簡訊]]、社群平台、購物平台、交友軟體或詐騙電話轉到 LINE 私下對話，再由假客服、假專員或群組裡的「理財導師」接手。

## 常見手法
- [[假網拍]]：偽造的「官方 LINE 客服」「銀行專員 LINE」
- [[解除分期付款]]：假客服提供 LINE ID
- [[假投資]]：LINE 投資群組，裡面有「理財導師」與暗樁
- [[假冒名人詐騙]]：「加 LINE 好友」「加入 LINE 群組」
- [[假求職]]：要求私下加 LINE
- [[騙取金融帳戶]]：求職版要求私下加 LINE（src-12）
- [[釣魚連結]]：貸款簡訊邀請加 LINE 諮詢
- [[色情應召詐騙]]：在交友軟體認識後加 LINE 好友
- [[假檢警]]：要求被害人「加 LINE 定時回報」

## 平台特有風險
- 被引導離開原本的購物或交友平台，改在 LINE 私下聯繫，就失去原平台的交易保障；src-01 的假網拍與解除分期防範方法都提醒避免用通訊軟體私下交易。
- 詐團會偽造「官方客服」「銀行專員」帳號。
- 假冒公務機關的詐團會用 LINE 持續控制被害人，要求定時回報。
- LINE 也是假冒名人廣告出現的地方之一（src-03）。

## 相關統計
- 新北市（扣除一六五受理）：「盜（冒）用 LINE 帳號」占 1.66%（見 [[新北市詐欺被害統計]]）。
