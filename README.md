# 台灣常見詐騙手法 LLM Wiki

依照 Karpathy 的 [LLM Wiki 構想](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)，用 LLM 把 17 篇新聞與警政資料整理成 68 頁互相連結的知識庫。重點不只是內容，而是展示 **ingest（匯入）→ query（提問）→ lint（健檢）** 三種操作如何讓知識持續累積。

## 怎麼看

建議用 **Obsidian** 開啟整個 `scam-wiki/` 資料夾，打開關係圖（Graph view）可以看到頁面之間的連結。

建議的閱讀順序：

1. [wiki/index.md](wiki/index.md)：全站目錄，每頁一行摘要
2. [165打詐儀錶板統計](wiki/統計/165打詐儀錶板統計.md)：全國詐騙的整體樣貌
3. [假網拍](wiki/手法/假網拍.md)、[假檢警](wiki/手法/假檢警.md)：資料最完整的兩個手法頁
4. [年輕人最常遇到的詐騙](wiki/分析/年輕人最常遇到的詐騙.md)、[長輩最該防的詐騙](wiki/分析/長輩最該防的詐騙.md)：由 query 產生的分析頁
5. [wiki/log.md](wiki/log.md)：每一次操作的紀錄

## 三層架構

| 層 | 位置 | 說明 |
|---|---|---|
| 原始資料 | `raw/`（17 篇，**未放上 GitHub**：新聞全文有著作權，原文網址見各來源頁） | 事實來源，LLM 只能新增、不能修改 |
| wiki | `wiki/`（68 頁） | LLM 撰寫與維護的頁面 |
| schema | [AGENTS.md](AGENTS.md) | 規定結構、頁面格式與三種操作流程；`CLAUDE.md` 只引用它 |

## 整理後看到的三個發現

1. **件數多的手法和損失大的手法不一樣**：2026 年 6 月，網路購物件數占 29%，財損只占 7%；假交友（投資詐財）件數 8%，財損卻占 22%；假檢警件數沒進前五，財損排第 3。
2. **年齡決定你會遇到什麼詐騙**：新北市 12–17 歲女性被害案件中，將近一半是假網拍；65 歲以上則以假投資為首，假冒機構和猜猜我是誰比 40–64 歲暴增數倍。
3. **贓款跑得比攔阻快**：詐騙贓款轉進虛擬貨幣交易所，平均 6.29 分鐘就換成虛幣，比 ATM 提領快約 19 倍。

## 限制

- `raw/13`–`raw/17` 是上網搜尋取得的資料。因為原網站不允許全文轉載，存的是**重點摘要，不是原文全文**，frontmatter 有註明。
- 年齡交叉資料只有新北市一個地區。
- 新北市的「假冒機構（公務員）詐財」對應到假檢警，是本 wiki 的推定，頁面上有註明。
- 虛擬遊戲詐騙只有統計，沒有劇本。

## 繼續使用

對 Claude Code 或 Codex 下指令即可，流程都寫在 [AGENTS.md](AGENTS.md)：

- `ingest 18`：匯入新放進 `raw/` 的資料（討論模式）
- `ingest 18-20 快速`：快速模式
- 直接提問：會先讀 index 再作答，答完問你要不要存成分析頁
- `lint`：健檢，必要時上網補資料
