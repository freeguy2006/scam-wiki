# 虛擬貨幣洗錢

## 定義
詐團把贓款轉入虛擬貨幣交易所、換成虛擬貨幣以轉移的洗錢方式。

## 運作方式
- 根據[[遠東商業銀行]]統計，近 4 成詐騙贓款會轉進虛幣交易所，轉移一半款項平均只要 6.29 分鐘，比轉帳、ATM 提領快得多，留給機關和業者攔阻的時間最短（見 [[詐騙贓款流向統計]]）。
- 防制方式：警方受理後透過「警示帳戶聯防通報子系統」通報銀行；如果收款帳號綁定虛幣交易所，銀行會把虛擬帳號列為[[警示帳戶]]，並以 API 通報交易所。警方正推動交易所直接納入子系統。
- 法制：《[[詐欺犯罪危害防制條例]]》2026-01-21 修正後，金融機構與虛擬資產業者可以跨業照會、聯防通報。
