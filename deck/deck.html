詐騙的基本樣貌：誘餌 → 轉私聊 → 假身分 → 要你轉錢或交帳戶

  1. 誘餌：低價熱門商品、「你中獎了」、高報酬打工
  2. 轉私聊：被帶到 LINE 私聊
  3. 假身分：假客服、假專員、「銀行專員」接手
  4. 動錢：操作 ATM、網銀，或交帳戶當人頭戶
來源：LINE、中獎通知、假求職、假網拍、解除分期付款
進入個別手法前，先用四種手法的定義歸納共同流程。第一步誘餌：假網拍是低價、熱門或「免費贈送」的商品；中獎通知是假抽獎活動或「你中獎了」的通知；假求職是低門檻、高報酬的打工或兼職。第二步轉私聊：幾乎每種手法都會把被害人從簡訊、社群平台、購物平台、交友軟體或詐騙電話轉到 LINE 私下對話。第三步假身分：再由假客服、假專員接手；詐團會偽造「官方客服」「銀行專員」帳號；解除分期付款則是假冒買家、平台客服或銀行員。第四步要你轉錢或交帳戶：藉付款、驗證之名騙走存款；以賣場金流或帳戶認證出問題為由誘導操作 ATM、網銀；以稅金、手續費、認證費名目要求一再匯款；或騙走金融帳戶當人頭戶。請同學記住這條流程，後面四頁都是它的變體。

跨手法常見的紅旗：被轉到 LINE、假客服接手、叫你動錢

出現在哪些手法紅旗
共同轉 LINE 私聊，假客服接手
共同客服帳號可能偽造
假網拍、解除分期「驗證」操作 ATM、網銀
假網拍只是驗證不會扣款、開視訊
解除分期、中獎通知要個資
來源：LINE、中獎通知、假網拍、解除分期付款、防詐五不
本頁標明每項紅旗的適用範圍，不說「四種手法都有」。幾乎每種手法都有的：被害人從簡訊、社群、購物平台或電話被轉到 LINE 私下對話，再由假客服、假專員接手；離開原平台改用 LINE 私下聯繫，就失去原平台的交易保障；LINE 上的「官方客服」「銀行專員」帳號可能是詐團偽造。假網拍與解除分期付款共同的：被要求操作 ATM 或網路銀行，而且都以「驗證」為名，假網拍的假客服、假銀行專員藉口驗證要求操作網銀、ATM、行動支付或無卡提款，解除分期付款的假銀行員要求依指示操作 ATM、網銀轉帳「驗證」。只出自假網拍的：對方說「只是驗證，不會扣款」這句原話，以及轉帳後被要求開視訊、分享螢幕或輸入驗證碼。要個資這一項不標「共同」：解除分期付款的假賣場客服會以「未簽署金流服務協議」等名義要求個資與身分驗證，中獎通知會要被害人點連結、填個資；防詐五不的「個資卡號不傳」是一般原則，不是四種手法共同紅旗。

小測驗（一）：假網拍與解除分期付款

Threads 送手機，要你加 LINE 操作網銀「只是驗證，不會扣款」，你該？

假網拍先引導加 LINE，再由假客服用「帳戶遭凍結」要求操作網銀、ATM 或無卡提款，說「只是驗證，不會扣款」；要你傳「無卡提款資訊」百分之百是詐騙。正確做法：避免透過通訊軟體或社群網站和賣家私下交易，不依指示操作 ATM 或網路銀行，掛斷後自己撥打 165 查證。

出處：165反詐騙諮詢專線、假網拍、解除分期付款

剛網購完，「客服」說訂單誤設分期，「銀行」叫你去 ATM 解除。你該？

這是解除分期付款的「騙買家」劇本：下單後假商家客服來電稱訂單誤設分期付款，接著假銀行人員指示到 ATM 轉帳說是「退款」或解除設定。剛網購完就接到「客服」來電說訂單有錯就是紅旗。正確做法：不依指示操作 ATM 或網路銀行，掛斷後自己撥打 165 查證。
