# 解除分期付款

## 一句話定義
詐團假冒買家、平台客服或銀行員，以賣場金流或帳戶認證出問題為由，誘導被害人操作 ATM、網銀或購買遊戲點數，把錢轉出去。目前資料涵蓋「假買家騙賣家」這個變體；騙買家的變體待後續來源補充。

## 典型劇本
### 假買家騙賣家
1. **假冒買家**：私訊賣家，或偽裝成官方平台訊息，稱賣場連結無法下單，轉而提供假客服連結、QR Code 或 [[LINE]] ID。
2. **假賣場客服**：以「賣家未簽署金流服務協議」或「帳戶認證」等名義，要求賣家提供個人資料進行身分驗證。
3. **假冒銀行員**：要求賣家依指示操作 ATM、網銀 APP 匯款，或購買[[遊戲點數]]。

## 常見管道
- 購物平台私訊、偽裝成官方的平台訊息
- [[LINE]]（假客服提供 LINE ID）

## 常冒用的身分
- 買家
- 賣場客服
- 銀行員

## 辨識關鍵字／紅旗
- 「未簽署金流服務協議」「帳戶認證」「賣場金流協議認證」
- 買家主動提供客服連結、QR Code、銀行網站連結
- 被要求操作 ATM 或網路銀行

## 應對方式
- 使用經認證的合法交易平台，避免用通訊軟體和買家聯繫。
- 不點擊買家提供的客服或銀行網站連結。
- 看到「未簽署金流服務協議」「帳戶認證」等字眼，就中止交易、立即查證。
- 不依指示操作 ATM 或網路銀行。
