## 重點摘要
1. [[165打詐儀錶板]]：2026 年 6 月受理詐騙 11,437 件、財損 47 億 417 萬元，比去年同期（16,388 件、89 億 1,509 萬元）分別下降 30% 與 47%。
2. 件數前五：網路購物（[[假網拍]]）29%、[[假投資]] 11%、假交友（投資詐財）8%、[[色情應召詐騙]] 6%、[[釣魚連結]] 5%。
3. 財損前五：假投資 32%、假交友（投資詐財）22%、[[假檢警]] 20%、網路購物 7%、假交友（徵婚詐財）3%。
4. 遠銀統計（2025-02-18 至 2026-06-23）：詐騙款項轉帳占 46%、轉入虛幣交易所 38%、ATM 提領 16%；轉移 50% 款項的平均時間，交易所換成虛幣只要 6.29 分鐘，轉帳 61.93 分鐘，ATM 提領 119.8 分鐘（見 [[虛擬貨幣洗錢]]）。
5. 同期間透過 API 雙向通報、臨櫃關懷、轉帳與 ATM 攔阻，共攔下逾 4 千筆、近 5.5 億元，其中 API 通報近 3 千筆、逾 3 億元。刑事局 2026-01-08 與遠銀簽署防詐合作備忘錄。
6. [[警示帳戶]]聯防通報子系統：銀行會把綁定交易所的虛擬帳號列為警示，再以 API 通報交易所；警方正推動交易所直接納入這個子系統。
7. 《[[詐欺犯罪危害防制條例]]》2026-01-21 修正公布，建立金融機構與虛擬資產業者跨業照會、跨機構防詐平台、異業聯防通報的法制基礎。
8. 儀錶板預計從 2026 年 8 月起，把詐欺案區分為電信網路詐欺、非電信網路詐欺、假性財產犯罪（交易糾紛、債務等）。
