# LINE

## 平台簡介
通訊軟體。在 src-01 中，LINE 多次是詐團把被害人從其他管道（簡訊、購物平台、交友軟體）轉到私下對話的工具。

## 常見手法
- [[釣魚連結]]：貸款簡訊邀請加 LINE 諮詢
- [[解除分期付款]]：假客服提供 LINE ID
- [[色情應召詐騙]]：在交友軟體認識後加 LINE 好友

## 平台特有風險
- 被引導離開原本的購物或交友平台，改在 LINE 私下聯繫，也就失去了原平台的交易保障；src-01 的假網拍與解除分期防範方法都提醒避免用通訊軟體私下交易。
